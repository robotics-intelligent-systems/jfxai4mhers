# AI-Powered Robotic Exoskeleton Simulation Platform

IAI Naive Kinematics serves as simulation node within projection framework. Berkeley Humanoid Lite is an open-source humanoid robot. ToddlerBot Open-Source ML-Compatible Humanoid Platform for Loco-Manipulation. Agile Open-Source Humanoid Robot for Research. Open-source humanoid robot platform Pib. NEST is a simulator for spiking neural network model. Smart Multi-Agent Robot Task Planning using LLM. RobotML stands for Robot Modelling language. DOGlove is a dexterous manipulation with a Low-Cost Open-Source Haptic Force Feedback Glove. rviz is a 3D visualizer for the (ROS) framework. URDF models of humans created to perform human robot interaction experiments. NVIDIA Isaac Sim is an open-source application on NVIDIA Omniverse for developing, simulating, and testing AI-driven robots in realistic virtual environments. OpenBCI is an open-source brain–computer interface platform. OpenExo, an open-source exoskeleton platform for mobility and rehabilitation research. ALICE is an Open-Source pediatric robotic exoskeleton. Open source simulator developed for the CoMan humanoid robot as part of WALK-MAN European project. OpenArm is an open-source 7DOF humanoid arm designed for physical AI research and deployment in contact-rich environments. Open-TeleVision Teleoperation with Immersive Active Visual Feedback. ROS 2 packages for the ROBOTIS OpenMANIPULATOR platform provide the necessary interfaces and tools to control the robot, integrate with its sensors, and develop physical AI applications. Modular HHCM app will genereate URDF, SRDF and a complete ROS package, which can be used to simulate and control the robot. Horizon is a framework for trajectory optimization and optimal control for robotics based on CasADi. Open source release of dexterous robotic hand, BiDexHand. IR-SIM is a lightweight robot simulator based on Python, designed for robotics navigation, control, and learning. TidyBot++ is an open-source Holonomic Mobile Manipulator for Robot Learning

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
